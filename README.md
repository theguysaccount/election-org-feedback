# Improve Election.org

Help make public civic information easier to find, understand and use. This repository is the public issue board for Election.org: bugs, feature requests and source-backed corrections. It contains no application source code or private user records.

- [Open a report or idea](https://github.com/theguysaccount/election-org-feedback/issues/new/choose)
- [Suggest something without a GitHub account](https://election.org/feedback)
- [See shipped updates](https://election.org/changelog)
- [Review data coverage and limitations](https://election.org/coverage)

Keep reports focused on the website and public sources. Never post credentials, private addresses, personal correspondence or information about somebody's private political views. For a source correction, link to an official public record and explain the exact discrepancy.

Ideas guide priorities; they do not automatically change public facts or promise a release date. We welcome respectful, constructive contributions across political viewpoints.
